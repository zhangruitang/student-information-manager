# 学生信息管理

面向计算机科学与技术、网络空间安全专业的单文件学生信息管理页面。使用原生 HTML、CSS 和 JavaScript 编写，无需安装依赖、构建项目或配置数据库，下载后即可在本地打开。

本仓库提供空名单版本，已移除内嵌的真实学生数据、历史核对记录及针对特定学生的旧数据修正内容。

## 文件

```text
.
├── index.html   # 页面、样式及交互逻辑
└── README.md    # 使用说明
```

## 开始使用

1. 下载仓库 ZIP 并解压，或将仓库克隆到本地。
2. 使用浏览器打开 `index.html`。建议使用较新版本的 Chrome 或 Edge。
3. 点击“新增学生”录入信息，或使用“导入 JSON”导入本页面支持的数据文件。

首次打开时名单为空。无需启动服务器，也不依赖在线脚本或第三方 CDN。

## 主要功能

- 学生信息新增、编辑、删除，以及当前会话内的撤销和重做。
- 全局查找、按列筛选、排序与按显示列组合去重。
- 显示列选择、列顺序调整、列宽调整及板块折叠。
- 专业、班级等统计图表，可与明细筛选联动。
- 缺失字段、电话格式、身份证与出生日期一致性、寝室人数等信息核对。
- 当前视图 CSV 导出、完整 JSON 导出与导入。
- 在浏览器支持并经用户授权时写回 HTML；不支持时下载更新版 HTML。

核对结果用于提示疑点，不会自动判断资料真伪或替代人工确认。

## 数据保存与备份

日常编辑保存到当前浏览器的本地存储（localStorage），不会自动修改磁盘中的 `index.html`，也不会自动同步到 GitHub 或其他电脑。清理浏览器数据、使用无痕窗口、更换浏览器或更换文件位置后，原来的本地数据可能无法读取。

建议定期点击“导出完整 JSON”保存备份。换电脑时，在另一台电脑打开页面并导入 JSON；导入前请查看变更预览，导入会按所选文件更新完整名单，包括删除当前名单中未出现在导入文件里的学生。

需要将数据保存在 HTML 中时，请使用页面提供的写回或下载更新版 HTML 功能，并确认文件已保存。浏览器对直接写入文件的支持可能不同。

## 仓库中的数据

本仓库只保存空名单页面和使用说明。录入数据后，导出的 JSON、CSV 以及写回或下载的 HTML 都可能包含个人信息；如需保持仓库为空名单版本，请将这些备份保存在仓库之外，并在后续提交前检查 HTML 的内嵌数据。

页面没有账号系统、服务器数据库或多人实时同步功能；本地打开即可使用，GitHub 仓库用于保存代码版本。
