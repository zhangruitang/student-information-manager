# 学生信息管理系统

一个可在浏览器本地使用的通用学生信息管理工具。使用原生 HTML、CSS 和 JavaScript 编写，界面、样式和交互都包含在一个 HTML 文件中，无需安装依赖、构建项目或配置数据库。

支持自行填写学院、专业、班级与班级号，学号不限定固定长度，可用于不同班级和专业的学生资料整理。首次打开后，按自己的需要新增学生或导入名单即可。

## 文件

```text

├── index.html   # 学生信息管理系统
└── README.md    # 使用说明
```

## 开始使用

1. 下载仓库 ZIP 并解压，或克隆仓库到本地。
2. 使用浏览器打开 `index.html`，建议使用较新版本的 Chrome 或 Edge。
3. 点击“新增学生”填写资料，或使用“导入 JSON”导入兼容的数据文件。

页面无需启动服务器，也不依赖在线脚本或第三方 CDN。GitHub 仓库页面用于查看和下载源文件，使用时请打开下载后的 HTML。

## 主要功能

- **资料维护**：新增、编辑和删除学生信息，记录身份、学籍、联系方式与住宿资料；支持当前会话内的撤销和重做。
- **查找筛选**：全局查找、按列筛选、排序，以及按显示列组合去重。
- **表格设置**：选择显示列、调整列顺序和列宽、折叠板块，并保存常用视图设置。
- **统计概览**：按专业、班级等维度查看统计图表，并与学生明细联动筛选。
- **信息核对**：提示缺失字段、重复学号、电话格式、身份证与出生日期一致性、同班资料一致性等问题。
- **数据交接**：导出当前视图 CSV、导出和导入完整 JSON，查看导入变更预览。
- **HTML 备份**：浏览器支持并经用户授权时写回 HTML；不支持时下载更新后的 HTML。

姓名和学号为新增学生时的必填项，学号需唯一。班级和班级号可自行填写，系统不会套用固定专业或学校的班级编码。

当前电话和身份证校验按中国大陆常见格式处理，寝室号统一为“楼栋号+栋+房间号”，并按每寝室最多 4 人进行检查。其他地区或不同住宿制度可按需调整源代码中的校验规则。核对结果用于提示疑点，不会替代人工确认。

## 数据保存与备份

日常编辑保存在当前浏览器的本地存储（localStorage）中，不会自动修改磁盘中的 `index.html`，也不会自动同步到 GitHub 或其他电脑。清理浏览器数据、使用无痕窗口、更换浏览器或更换文件位置后，原来的本地数据可能无法读取。

建议定期点击“导出完整 JSON”保存备份。换电脑时，在另一台电脑打开页面并导入 JSON。导入前请查看变更预览：导入会更新完整名单，当前名单中未出现在导入文件里的学生也会被移除。

需要把数据保存到 HTML 时，请使用页面的写回或下载更新版 HTML 功能，并确认文件已保存。浏览器对直接写入文件的支持可能不同。

## 数据与适用范围

仓库未预置学生个人信息。录入资料后，导出的 JSON、CSV 和保存数据后的 HTML 都可能包含个人信息，请妥善保存，不要将真实名单提交到公开仓库。

页面没有账号系统、服务器数据库或多人实时同步功能，适合本地个人使用与文件交接。
