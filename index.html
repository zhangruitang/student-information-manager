更新规则

  1. 按学号匹配学生。同一学号的字段使用 JSON 中的值；空值也会覆盖现有内容。
  2. JSON 中新增的学号会添加；当前名单中存在、JSON 中没有的学号会删除。所有学生均参与更新，不受当前筛选或隐藏列影响。
  3. 名单顺序以 JSON 为准；导入后清除筛选和行排序，显示列、日期显示格式和页面功能保留。
  4. 确认后更新全部学生数据、浏览器保存的数据及 HTML 内嵌数据。直接写回不可用时，改为下载更新后的 HTML，原文件不会被直接修改。
  5. 更新前自动备份当前学生数据，可通过“恢复导入前数据”恢复；取消操作不更改数据和文件。
